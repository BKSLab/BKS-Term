# 0023 — Общая история ответов и вывода команд TUI

Статус: принято, 2026-11-06, preview.33. Уточняет 0015 и исправление preview.32.

Переключение с архива ответов на текущий исходный экран позволяло прочитать
`/status`, но не сохраняло результат после следующего ввода и перерисовки.
Пользователю нужна история блоков вывода с едиными переходами.

TurnLog хранит Answer и Command в общей последовательности стабильных ID.
Индексы ответов и модельный lifecycle остаются отдельными от индекса всех
блоков. Общий документ и Ctrl+Up/Down включают оба вида; Ctrl+Shift+R открывает
последний новый блок, а до его подтверждения доступен исходный экран.
Заголовок команды — обычный текст. Только заголовок запроса модели может
раскрываться; никакой текст журнала не исполняется.

Для Codex команда привязывается к успешно переданному явному Enter и
подтверждённому исходному полю либо выбранной slash-подсказке. Tab сам не
создаёт результат: недавний выбор требует точного видимого завершённого поля
перед Enter. После отправки требуется пустой подтверждённый composer, закрытое
меню и устойчивый реальный блок после plain echo команды. Сохраняются только
его текст и оформление до поля; footer и подсказки исключены. Повторный
`/status` может использовать прежние клетки без новой печати slash-строки,
поэтому сохраняется snapshot подтверждённого результата, а не придуманная
новизна по числу echo. Результат не создаёт событий model Ready/Phase.

Следующий явный ввод завершает захват предыдущей команды. Смена геометрии,
буфера, адаптера, выход из direct mode и очистка отменяют незавершённое
доказательство. При неоднозначности остаётся исходное чтение без нового блока.
Уже сохранённые блоки не зависят от VT-экрана. Общие пределы — 128 записей и
2 МиБ; активный ответ и новейший результат защищены от взаимного вытеснения,
старый текст ограничивается с отметкой. Один результат команды — до 128 КиБ.
История живёт только в памяти вкладки, не переносится из предыдущих запусков.

Приёмка: реальные изолированные Codex captures через Session, тесты отрицательных
случаев и нативный RichEdit/UIA. Фактическую речь NVDA подтверждает человек.
