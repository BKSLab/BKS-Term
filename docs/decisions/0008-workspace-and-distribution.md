# 0008 — Рабочие папки, окна, конфигурация и пакеты

**Дата:** 26.10.2026. **Статус:** реализация предварительной версии.

Новые окна — отдельные процессы текущего EXE. Их запускают через Command с
раздельными аргументами, без shell interpolation. `--profile` означает явный
выбор; `--choose-profile --cwd` открывает меню без преждевременной сессии.
Обычный запуск использует локальную оболочку из discovery, а не сохранённый
default с возможными SSH/командами. Рабочая папка задаётся CreateProcessW
конкретного ConPTY; cwd родителя не меняется.

Карта shortcuts валидируется при вводе и десериализации. Native editing и
системные клавиши защищены; F1 и Ctrl+Shift+Space обязательны. Terminal-only
команды не перехватывают навигацию обычного EDIT. Текущие сочетания показаны
в F1 и соответствующих пунктах меню.

Недавние профили — opt-in список ID/начальных папок, без текста команд,
вывода или секретов. Восстановление требует выбора. Межоконные записи
сериализуются неблокирующим ConfigLock. SSH-save читает latest disk и
проверяет target conflict; новые ID не перезаписывают чужие. Preferences
сохраняются при совпадении baseline; изменение speech mode объединяется с
последней конфигурацией. MRU перечитывает latest и уважает opt-out другого окна.

Explorer integration меняет только два HKCU verb по явному флагу. Обновление
и удаление требуют совпадения owner executable и точной команды. Установщик
не включает Explorer автоматически; uninstall удаляет только принадлежащие
установленной программе записи.

MSVC EXE статически линкует CRT и содержит asInvoker/common-controls manifest
и ProductVersion. Setup — asInvoker .NET Framework WinExe с embedded ZIP,
запускающий per-user installer. IExpress был доступен, но не собирал минимальный
SED в данной среде; дополнительный compiler/admin не требуются благодаря
встроенному Framework C# compiler. Package проверяет пути, hashes, version,
DLL-зависимости, собственное extraction и не включает пользовательские данные.
Удаление сохраняет неизвестные/изменённые файлы и конфигурацию по умолчанию.

Публикация и подпись не выполняются автоматически. CI описан локально;
проверка чистой VM, реального Explorer и речь NVDA остаются отдельной приёмкой.
