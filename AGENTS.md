# AGENTS.md — BKS Term

Точка входа для AI-агентов. Прочти этот файл первым.

## Что за проект

BKS Term — доступный терминал для Windows (NVDA-first) на Rust: нативный Win32 UI, ConPTY, VT-ядро, Semantic Accessibility Engine. Подробности:

- `docs/concept.md` — концепция, стек, архитектура, критерии успеха.
- `docs/setup-and-iterations.md` — установка среды и итерационный план (Этапы 0–8).
- `MEMORY.md` — **текущее состояние**: что сделано, среда, нюансы, следующая итерация. Обновляй его после каждой завершённой итерации.

При противоречиях: концепция и план важнее памяти; архитектурные изменения фиксировать отдельным решением (ADR в `docs/decisions/`, когда появится код).

## Ключевые правила

- Одна итерация = одна проверяемая возможность; каждая итерация завершается запускаемым `.exe`.
- После этапа обязательно: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `cargo build --release`. Не писать «проверено», если не запускалось.
- Доступность (NVDA) проверяет только человек. Агент никогда не объявляет NVDA-тест пройденным по автотестам.
- Не исполнять автоматически команды/подтверждения, распознанные из текста TUI.
- Коммиты и push — только по явному разрешению пользователя.

## Среда (установлено 23.10.2026)

Rust 1.99.1 stable MSVC (`x86_64-pc-windows-msvc`), clippy, rustfmt, VS 2022 Build Tools 17.14.39 (VCTools). Если `cargo` не в PATH: `C:\Users\user\.cargo\bin`.

## Генерация кода через DeepSeek (скилл deepseek-coder)

- Скрипт: `C:\Users\user\.kimi-code\skills\deepseek-coder\deepseek_codegen.py` (есть только у Kimi Code).
- **Правило: одно ТЗ = один модуль/класс/файл** (выходные токены — основной расход; лимит `--max-tokens` по умолчанию 16000, код выхода 3 = ответ обрезан, дроби ТЗ).
- Вывод DeepSeek никогда не применять вслепую: переносить вручную, проверять сборкой и тестами.
- Черновики — в `.deepseek/`, в git не коммитить.
