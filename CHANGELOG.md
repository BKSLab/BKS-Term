# Журнал изменений

Версия исполняемого файла и пакетов берётся из `crates/bks-app/Cargo.toml`.
Предварительные сборки имеют суффикс SemVer; принятие с NVDA и на чистой VM
фиксируется отдельно от результатов автотестов.

## 0.4.0-preview.6 — 2026-10-27

- Shift+навигация начинает нативное выделение в документе чтения от текущего
  курсора TUI; выделение/копирование не отправляют сочетания в приложение.
- Подсказка выбранного пункта озвучивается без указателя; поддержано
  доказанное перемещение других маркеров между устойчивыми названиями.
- Отдельное нативное меню не возвращается; ввод и изоляция отрисовки сохранены.

## 0.4.0-preview.5 — 2026-10-27

- По просьбе пользователя удалено пробное нативное меню выбора и слеш-команд;
  доступны собственный TUI инструмента и прежний обзор экрана.
- VT рисуется отдельной непрозрачной поверхностью поверх доступного поля
  в той же области: нативная прокрутка поля больше не двигает пиксели VT.
- Сохранены подтверждённое пользователем озвучивание набора, фокус и
  стандартный текстовый провайдер; дополнительного поля ввода не появляется.

## 0.4.0-preview.4 — 2026-10-27

- Исправлено эхо набора в заполненных пробелами строках с рамкой и программным
  курсором; Unicode и перемещение редактора подтверждаются по живому VT.
- Ctrl+Shift+D показывает уверенно распознанные пункты выбора и слеш-команд
  в нативном меню с зелёно-чёрным градиентом и сохранённой доступностью Windows.
- Выбор обновляется на месте без сброса списка, прокрутки и повторной смены
  заголовка; графическая область ввода сохраняет видимость при обновлении текста.

## 0.4.0-preview.3 — 2026-10-27

- Простой запуск Kimi/Codex/Claude/Gemini из нативного поля автоматически
  передаёт ввод TUI; поле больше не блокирует работу уже запущенного CLI.
- Возврат того же приглашения родительской оболочки восстанавливает редактор;
  активное чтение сохраняется до явного возврата, черновики не исполняются.
- Переключение shell/TUI не меняет размер ConPTY и не провоцирует повтор экрана.
- Начальные пустые строки разметки ConPTY после раннего resize не добавляются
  в журнал; отступы и последующие пустые строки команд сохранены.

## 0.4.0-preview.2 — 2026-10-27

- Обычным оболочкам возвращены нативный редактор команды и журнал:
  выделение, удаление, Tab и навигация по блокам Ctrl+Up/Down.
- Прямой захват при запуске ограничен отдельными CLI-профилями. В TUI
  Ctrl+Up/Down открывают чтение соседних строк без отправки клавиш в процесс.
- Дублирующая системная каретка скрывается после обновлений и изменения
  размеров с сохранением её объекта и позиции для экранного доступа.

## 0.4.0-preview.1 — 2026-10-27

- Единая рабочая область терминала без нижнего дублирующего поля; новая
  вкладка сразу принимает ввод. Нативный текстовый провайдер сохранён поверх
  той же VT-поверхности, с Unicode-кареткой и независимым документом чтения.
- Озвучивание подтверждённого видимого ввода; скрытые/замаскированные символы
  и перерисовки не используются как эхо набора.
- Ctrl+Shift+L читает текущую строку, Ctrl+Shift+R открывает новый вывод;
  Esc и Ctrl+Shift+Space возвращают из чтения сразу к управлению TUI.
- Нативный диалог TUI получил явное живое управление клавишами, ожидание
  ответа, защиту от повторов и устаревших экранов; обычный снимок остаётся стабильным.
- Новые горячие клавиши сохраняют ранее назначенные пользовательские сочетания.

## 0.3.0-preview.1 — 2026-10-27

- Общий read-only обзор любого TUI по Ctrl+Shift+D: исходный контекст,
  нативный список строк, возможное выделение и явный возврат к прямому вводу.
- Обратная связь после навигации учитывает перенос подсветки, инверсии
  и видимого курсора. Одиночные, массовые и неоднозначные смены оформления тихие.
- Анализ известного диалога Codex вынесен в отдельный ограниченный процесс;
  таймаут/повреждённый ответ/выход отключают улучшение, сохраняя терминальную сессию.
- Установленные Codex, Kimi, Claude и Gemini обнаруживаются в фоне;
  режимы экранного доступа Claude/Gemini предлагаются отдельными профилями.
- Новая версия CLI сохраняет обычный запуск; проверенные действия по-прежнему
  требуют поддержанного экрана и актуального исходного состояния.
- Первый запуск сохранённого CLI-профиля получает подтверждение версии после
  фонового обнаружения; запуск CLI в новом окне дожидается своего профиля,
  сохраняет рабочую папку и отменяется при выборе другой сессии.
- Исправлен запуск CLI на .NET из обычных Windows-путей с сохранением
  проверки идентичности исполняемого файла.
- Исправлены корреляция уведомлений в native-оснастке и классификация внешнего
  ввода как ошибки среды; добавлены проверки изоляции отказа и независимых PTY.
- Реальная речь NVDA, полные сценарии с моделями и чистая Windows остаются
  отдельной ручной приёмкой. Сборка сохраняет статус prerelease.

## 0.2.0-preview.2 — 2026-10-26

- Исправлен недоступный фокус прямого ввода: нативное текстовое поле с живым
  VT-документом и кареткой принимает клавиши для дочернего приложения.
- Добавлена ограниченная обратная связь об устойчивых изменениях строк
  после явной навигации по TUI; чтение не подтверждает действия.
- Исправлено выключение захвата повторным Ctrl+Shift+I; независимые
  закладки полного документа чтения и черновик команды сохраняются.
- GDI-кадр собирается вне экрана и выводится одной операцией, чтобы
  промежуточная очистка фона не была видна при перерисовке TUI.
- Речь NVDA и отсутствие мерцания на реальном Kimi требуют ручного прогона.

## 0.2.0-preview.1 — 2026-10-26

Предварительная сборка. Ручная приёмка с NVDA и проверка на чистом ПК/VM
ещё требуются перед объявлением пользовательского релиза.

- Ограниченный журнал чтения, отдельный VT-документ, поиск и навигация по
  результатам команд; сохранение места чтения при обновлениях вывода.
- Настраиваемые объявления вывода и первый доступный диалог Codex CLI
  с явным действием пользователя и проверкой актуальности.
- Профили оболочек и SSH, отдельный защищённый ввод, встроенная справка.
- Отдельный клиент Codex App Server 0.164.0: новый текстовый диалог,
  поток ответа, прерывание и явные разовые решения по обычным командам.
- Новые окна и вкладки в выбранной папке, настройки сочетаний клавиш,
  поведение последней вкладки и необязательный список недавних профилей.
- Защита настроек и профилей от перезаписи изменениями другого окна;
  читаемая с клавиатуры подсказка про алиасы в редакторе SSH.
- Portable ZIP и установщик EXE для текущего пользователя, контроль SHA256,
  отчёт о DLL, сценарии обновления и удаления с сохранением настроек.
- Windows CI для форматирования, clippy, тестов, release-сборки и пакетов.

Состояние остальных возможностей и ограничения перечислены в README и справке.

## 0.1.0

Исходная версия workspace: нативное окно Win32, ConPTY, VT-ядро,
интерфейс терминала и основа доступности.
